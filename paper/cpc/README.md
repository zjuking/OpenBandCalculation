# CPC software paper (CPiP submission)

The CPC Computer Programs in Physics (CPiP) submission for this project:
the program description, its verification, and everything needed to reproduce
the numbers in it.

## Contents

| File | What it is |

| | verification suites classified by kind (analytic / operator / scale / contract); per-layer calibration in Section 2.2 |

| `highlights.txt` | 5 highlights, <= 85 characters each |

## Regenerating every number in the paper

```bash
python -m venv .venv
.venv/Scripts/pip install -e ".[web]" matplotlib      # or: source .venv/bin/activate

# 1. verification suites (their stdout is what Fig. 2 parses)
python tests/validate_physics.py > paper/cpc/data/validate_physics.out
python tests/validate_quantum.py > paper/cpc/data/validate_quantum.out
python tests/validate_strain.py  > paper/cpc/data/validate_strain.out
python tests/validate_fermi.py  > paper/cpc/data/validate_fermi.out
python -m uvicorn web.app:app --port 8123 &           # needs PYTHONPATH=src
python tests/web_smoke.py http://127.0.0.1:8123 > paper/cpc/data/web_smoke.out

# 2. timings and the spread scan
python paper/cpc/benchmark.py

# 3. the three audit scripts (current conservation, quantum mesh convergence,
#    strain sensitivity); each writes its JSON under paper/cpc/data/
python paper/cpc/current_audit.py
python paper/cpc/quantum_convergence.py
python paper/cpc/strain_sensitivity.py

# 4. figures (re-solves the devices; ~4 min)
python paper/cpc/make_figures.py
```

`make_figures.py --reuse` skips the solves and redraws from
`data/figdata.json`.

## Submission package

```bash
python paper/cpc/make_submission.py     # -> paper/cpc/dist/
```

`dist/` holds the manuscript files for individual upload, `obpds-2.0.zip` (the
repository as it stands: source, tests, example run, licence, reproduction
scripts) and `README-upload.md` mapping each item to an Editorial Manager item
type. The archive is built from disk, so nothing enters it that is not in the
repository. Verified by extracting it elsewhere and running the suites from the
extracted copy.

## Compiling

```bash
bash paper/cpc/build.sh          # pdflatex -> bibtex -> pdflatex -> pdflatex
```

Produces `manuscript.pdf`. The class is
`elsarticle` (`preprint,12pt`); the Program Summary uses the `refnummer`
environment from Elsevier's `cpc-cpip-template.tex`.

`build.sh` looks for MiKTeX in `%LOCALAPPDATA%\Programs\MiKTeX\miktex\bin\x64`
(override with `MIKTEX_BIN`). On this machine the plain `pdflatex` launcher was
not created by the per-user install, so the script drives
`miktex-pdftex --undump=pdflatex` instead; MiKTeX's `AutoInstall` fetches any
missing package from the TUNA CTAN mirror configured for it.

A copy of the built preprint is kept at `../OBPDS2-CPC-preprint.pdf`.
